Detector parameters & gate 

            
Confidence is an uncalibrated margin-based indicator, not a probability.
              Every supported pair needs at least 20 actual switches, precision ≥90% and recall ≥80%.
              Each separate control needs ≥30 seconds with zero detector switches.
              One passing report is not an overall release gate.
